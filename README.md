# 🚑 RapidCare – Online Ambulance Booking System

RapidCare is a web-based emergency ambulance booking system designed to help users quickly request ambulance services and manage emergency transportation efficiently.

This project focuses on solving real-world emergency response problems using a simple and user-friendly web interface.

---

## 📌 Features

- User registration and login
- Emergency ambulance booking
- Driver login and dashboard
- User profile management
- Booking status tracking
- Clean and responsive UI

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
